# Architecture Decision Records

Use ADR quando uma decisão afetar arquitetura, banco, autenticação, autorização, segurança, integrações, deploy, dados, tecnologia ou operação de forma relevante.

## Índice

- [ADR-001 — Adoção seletiva do ECC](./0001-selective-ecc-adoption.md)

## Convenção

Cada ADR deve registrar:
- status;
- data;
- contexto;
- problema;
- decisão;
- alternativas;
- consequências;
- trade-offs/riscos;
- impacto em segurança;
- impacto em dados/migrations;
- rollout;
- rollback;
- PR/commit relacionado.

Decisões substituídas devem ser marcadas como `superseded`, preservando histórico.
